Panduan Step-by-Step Setup Kunci Akses (Orang Awam Friendly)

LANGKAH 1: Dapatkan Gemini API Key (Gratis)

  1. Buka Google AI Studio di: aistudio.google.com/app/apikey
  2. Login menggunakan akun Google / Gmail Anda.
  3. Klik tombol biru "Create API Key".
  4. Salin kode kunci yang muncul (diawali dengan kata AIzaSy...).
  5. Buka menu Pengaturan API di web ini lalu tempelkan pada kolom Gemini API Key.

LANGKAH 2: Dapatkan Google Client ID & Salin JavaScript Origin

  1. Buka Google Cloud Console di: console.cloud.google.com
  2. Buat project baru atau pilih project yang sudah ada.
  3. Di menu pencarian atas, ketik "YouTube Data API v3" lalu klik ENABLE (Aktifkan).
  4. Masuk ke menu APIs & Services > Credentials.
  5. Klik Create Credentials > Pilih OAuth Client ID.
  6. Pilih Application type: Web Application.
  7. Di bagian "Authorized JavaScript origins", klik + ADD URI, lalu tempelkan URL Web Anda:
  8. Klik CREATE lalu salin string Client ID (diawali angka dan diakhiri .apps.googleusercontent.com).
  9. Tempelkan ke kolom Google Client ID di Pengaturan API web ini.
