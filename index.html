Gemini AI: Belum Set YouTube OAuth: Belum Set

1. Cara Mendapatkan Gemini API Key Gratis

  1. Buka Google AI Studio.
  2. Login dengan akun Google/Gmail Anda.
  3. Klik "Create API Key" lalu salin kunci yang dihasilkan ke kolom Gemini API Key di atas.

2. Cara Mendapatkan Google Client ID (YouTube Upload)

  1. Buka Google Cloud Console dan buat Project baru.
  2. Di menu APIs & Services > Library, cari dan aktifkan YouTube Data API v3.
  3. Di menu OAuth consent screen, pilih External, isi nama aplikasi, dan tambahkan email Anda sebagai Test User. Tambahkan Scope `.../auth/youtube.upload`.
  4. Di menu Credentials, klik Create Credentials > OAuth client ID.
  5. Pilih Application type: Web application.
  6. Di bagian Authorized JavaScript origins, masukkan URL website tempat Anda menghosting tools ini (misal `http://localhost`, `https://domainanda.com`, atau URL GitHub Pages Anda).
  7. Salin Client ID yang diberikan ke form di atas.
