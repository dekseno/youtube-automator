Panduan Setup Kunci Akses (100% Gratis)

Tools ini didesain 100% client-side tanpa server berbayar. Gunakan API Key pribadi Anda:

1. Cara Dapatkan Gemini API Key Gratis:

  1. Buka Google AI Studio.
  2. Klik Get API key -> Create API key.
  3. Salin kunci tersebut lalu tempel di kolom Pengaturan Aplikasi.

2. Cara Dapatkan Google Client ID (OAuth):

  1. Buka Google Cloud Console.
  2. Aktifkan YouTube Data API v3 di bagian APIs & Services.
  3. Buat OAuth 2.0 Client ID (Web application).
  4. Tambahkan URL GitHub Pages Anda di Authorized JavaScript origins.
